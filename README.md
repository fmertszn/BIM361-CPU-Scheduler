# BİM361 - CPU Zamanlama Simülatörü

Bu proje, BİM361 İşletim Sistemleri dersi dönem projesi kapsamında geliştirilen bir CPU Zamanlama Simülatörüdür. Proje; FCFS, SJF/SRTF, Round Robin ve Priority Scheduling algoritmalarının çalışma mekanizmalarını simüle etmek ve performans metriklerini (bekleme ve dönüş süreleri) karşılaştırmak amacıyla hazırlanmaktadır.

## Durum

Proje başlangıç aşamasındadır (Sprint 1). Veri yapıları iskeleti ve mini demo üzerinde çalışılmaktadır.

## Planlanan Özellikler

- FCFS, SJF (non-preemptive), SRTF, Round Robin ve Priority algoritmaları
- Süreçlerin dosyadan okunması
- Gantt Şeması ile yürütme akışının gösterilmesi
- Ortalama bekleme ve dönüş sürelerinin hesaplanıp algoritmalar arasında karşılaştırılması

## Gereksinimler

- Python 3.x

## Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

**1. Depoyu klonlayın:**
```bash
git clone https://github.com/fmertszn/BIM361-CPU-Scheduler.git
cd BIM361-CPU-Scheduler
```

**2. Programı çalıştırın:**
```bash
python main.py
```
